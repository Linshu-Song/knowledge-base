數據集設計

在實際工業界項目中，數據往往不會乖乖地躺在一個本地資料夾裡。你可能會面對本地的圖像檔案、雲端的 Parquet 表格、遠端資料庫游標或是 Kafka 的數據流。為了保持訓練程式碼的穩定性，我們需要一個具備高擴展性的 Dataset 架構。

兩類 Dataset 的分野​

PyTorch 原生支援兩種形態的數據集，它們對應著兩種截然不同的底層物理讀取模式：

Map-style Dataset​

  • 核心介面：實作 __getitem__() 和通常的 __len__()。
  • 適用場景：數據長度已知且支援 O(1)O(1)O(1) 隨機存取。例如本地圖像目錄、載入到記憶體的 DataFrame 或固定大小的索引檔案。
  • 優勢：完美適配 PyTorch 的各種採樣器（Sampler），可以輕鬆實現打亂（Shuffle）和按權重採樣。

Iterable-style IterableDataset​

  • 核心介面：實作 __iter__()，產出一個迭代器。
  • 適用場景：順序存取更自然，或者隨機存取成本極高的數據來源。例如流式資料庫讀取、超大日誌流解析、即時生成的對抗樣本。
  • 注意：由於沒有「全局索引」概念，Sampler（如隨機採樣、批採樣）不適用於此類數據集。

高可擴展性的分層設計​

為了同時兼容多種數據格式（Dataset Format）和不同儲存介質，最穩妥的做法是把「樣本語義」與「物理儲存讀取」解耦。

透過分層設計，可以構建一個靈活的數據預處理管線：

  • Source / Reader：處理「數據從哪裡來」。例如建立 S3 連線、讀取本地磁碟或打開資料庫句柄。
  • Decoder / Parser：處理「怎麼解析格式」。負責將原始位元流解碼為 NumPy、Tensor 或 PIL Image。
  • Dataset：承載抽象的「單樣本契約」。它只關心如何將解析後的數據映射為統一的業務欄位（如 image、label）。
適配器模式

不要為每一種數據源編寫不同的訓練程式碼。應當構建如 ImageFolderAdapter、ParquetAdapter、StreamAdapter 等類，並在內部完成從 Source 到底層 Dataset 的轉換。只要它們輸出相同的 Sample Schema，下游的訓練邏輯就無需任何改動。

高階 Dataset 組合操作​

很多時候，不需要從頭手寫所有邏輯，PyTorch 提供了一系列原語用於數據集的組合與切割：

工具類適用場景作用說明
ConcatDataset多數據集聯合訓練將多個 Map-style 數據集首尾拼接。類似於在行維度增加樣本量。
ChainDataset多流式源聯合將多個 IterableDataset 串接在一起，讀完一個流接著讀下一個流。
StackDataset多模態對齊例如 Dataset A 產出圖像，Dataset B 產出文本。Stack 可將其按索引並行對齊。
Subset劃分切分給定一個索引列表，生成原數據集的子集（常用於切分訓練集與驗證集）。

IterableDataset 與多進程陷阱​

數據重複風險

使用 IterableDataset 配合 DataLoader(num_workers > 0) 時，每個 worker 進程都會獲得 Dataset 物件的一個完整副本。如果不在 __iter__ 中手動切分，每個進程都會從頭讀取完全相同的數據，導致數據重複。

正確做法

必須在 __iter__() 中利用 torch.utils.data.get_worker_info() 進行分片處理，確保每個 Worker 只消費其負責的數據分片。

import math
from torch.utils.data import IterableDataset, get_worker_info

class MyStreamingDataset(IterableDataset):
    def __init__(self, start, end):
        self.start = start
        self.end = end

    def __iter__(self):
        worker_info = get_worker_info()
        if worker_info is None:  # 單進程模式
            iter_start = self.start
            iter_end = self.end
        else:  # 多進程模式，對數據進行切分
            per_worker = int(math.ceil((self.end - self.start) / float(worker_info.num_workers)))
            worker_id = worker_info.id
            iter_start = self.start + worker_id * per_worker
            iter_end = min(iter_start + per_worker, self.end)
            
        return iter(range(iter_start, iter_end))
IterableDataset Sharding

由於 IterableDataset 不具備全局索引，Sampler 和 BatchSampler 均無法與其配合使用。所有的採樣邏輯、Shuffle 邏輯都必須實現在 Dataset 內部。

透過這種分層和組合策略，可以構建起能夠支撐千萬級規模、靈活掛載多種儲存系統的現代深度學習數據底座。
