# PyTorch 教學

歡迎來到 PyTorch 教學知識庫！

本教學採用模組化的樹狀結構進行組織，專為可擴展式學習而設計。無論您是在建構第一個神經網路，還是在多個 GPU 上擴展大型語言模型，您都能在這裡找到相關的指南。

## 結構概覽

1. **基礎入門 (`01-fundamentals`)**：PyTorch 的基石，涵蓋張量操作和 `autograd` 自動微分引擎。
2. **核心工程組件 (`02-core-components`)**：您將每天使用的工程必備品：`Dataset`、`DataLoader`、`nn.Module`、自訂層和最佳化策略。
3. **高級進階與最佳化 (`03-advanced-optimization`)**：生產規模深度學習的技術，包括分散式數據平行 (DDP)、全切片數據平行 (FSDP) 和混合精度 (AMP)。
4. **高層框架 (`04-frameworks`)**：如 PyTorch Lightning 等自動化了樣板工程任務的高階函式庫。
5. **垂直領域實戰 (`05-domain-applications`)**：特定任務的垂直領域實現，涵蓋從電腦視覺和自然語言處理到時間序列預測的內容。
