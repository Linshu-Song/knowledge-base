# 進階數據管道

對於大規模資料集或串流傳輸場景，其中資料是動態生成或從遠端來源串流傳輸的，標準的對應樣式（Map-style）`Dataset` 變得低效或無法使用。PyTorch 提供了一個稱為 `IterableDataset` 的進階原語和一個稱為 `TorchData` 的專用函式庫。

## `IterableDataset` 和 `IterDataPipe`

常規的 `Dataset` 依賴於索引（`__getitem__`），而 `IterableDataset` 實作了 `__iter__` 協定，按順序生成資料點。

`IterDataPipe` 是 TorchData 中引入的一種較新的範式，它直接在可迭代資料流上連結操作（例如解析、解碼、批次處理）。

```python
from torch.utils.data import IterableDataset

class StreamingDataset(IterableDataset):
    def __init__(self, data_stream):
        self.data_stream = data_stream

    def __iter__(self):
        for data in self.data_stream:
            yield self.process(data)
```

`TorchData` 生態系統促進了可組合的資料載入管道。我們將涵蓋：

- **音訊管道**：與 `torchaudio.datasets` 整合並進行即時頻譜圖處理
