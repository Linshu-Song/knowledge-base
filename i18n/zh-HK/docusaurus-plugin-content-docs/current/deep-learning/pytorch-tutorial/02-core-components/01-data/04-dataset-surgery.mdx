# 資料集修改

在實際工程中，你極少需要從零開始手寫一個完整的 PyTorch `Dataset`。通常情況下，我們會從 `torchvision` 或 Hugging Face 下載標準資料集，這些資料「差不多」符合我們的需求，但總需要一些客製化的微調。

與其複製底層原始碼並重寫整個資料集類別，最佳實踐是**修改、包裝（Wrap）或組合**現有的資料集。本指南將展示如何進行優雅的「資料集手術」。

## 包裝器模式 (Wrapper Pattern)：修改輸出格式

假設你正在使用 `torchvision.datasets.CIFAR10`，它預設返回的元組是 `(image, label)`。但如果你在做對比學習，或者需要追蹤樣本，想要它返回 `(image, label, image_index)` 怎麼辦？

不要去重寫 CIFAR10 的類別，你可以建立一個**包裝器資料集 (Wrapper Dataset)**。它將原始資料集作為屬性接收，並在 `__getitem__` 階段攔截並修改輸出。

```python
import torch
from torch.utils.data import Dataset
from torchvision import datasets, transforms

class IndexWrapperDataset(Dataset):
    """包裝現有資料集，使其在返回資料的同時附加樣本的索引 (index)。"""
    
    def __init__(self, original_dataset):
        self.original_dataset = original_dataset
        
    def __len__(self):
        # 將長度查詢委託給原始資料集
        return len(self.original_dataset)
        
    def __getitem__(self, index):
        # 1. 獲取原始資料
        data, label = self.original_dataset[index]
        
        # 2. 修改它，或者追加自訂的資訊
        return data, label, index

# 使用方法
base_dataset = datasets.CIFAR10(root='./data', train=True, download=True, transform=transforms.ToTensor())
custom_dataset = IndexWrapperDataset(base_dataset)

img, label, idx = custom_dataset[0]
print(f"成功載入索引為 {idx} 的圖片，標籤為 {label}")
```

:::tip[覆寫資料增強 (Transforms)]
你同樣可以使用這種包裝器模式，在執行時動態修改、或向那些本身不支援複雜 Transform 流水線的資料集追加自訂的資料增強邏輯。
:::

## 切片與過濾：Subset 與 Splits

我們經常需要從龐大的資料集中抽取出極小的一部分用於快速 Debug 跑通程式碼，或者將一個完整的資料集切分為訓練集和驗證集。

### `random_split` (訓練/驗證集劃分)
如果官方資料集沒有預先切分驗證集，PyTorch 提供了 `torch.utils.data.random_split` 來幫你一鍵完成。

```python
from torch.utils.data import random_split

# 假設原始資料集有 10,000 張影像
full_dataset = datasets.FakeData(size=10000, image_size=(3, 224, 224), num_classes=10)

# 定義劃分長度 (長度總和必須等於總樣本數)
train_size = int(0.8 * len(full_dataset))
val_size = len(full_dataset) - train_size

# 隨機切分 (返回兩個 Subset 物件)
train_dataset, val_dataset = random_split(full_dataset, [train_size, val_size])
```

:::danger[Transform 的資料洩露問題]
新手在使用 `random_split` 時最容易犯的錯誤，是在切分**之前**就給 `full_dataset` 掛載了帶有隨機性的訓練增強（例如 RandomCrop 隨機裁剪）。這會導致你的**驗證集也被加上了隨機資料增強！**

**解決方案**：結合第 1 節介紹的「包裝器模式」，分別對切分出來的 `train_dataset` 和 `val_dataset` 包裝不同的 Transform 邏輯。
:::

### `Subset` (條件過濾)
如果你想根據某些特定條件手動篩選資料（例如，只保留特定類別的樣本），請使用 `Subset`。

```python
from torch.utils.data import Subset

# 過濾：僅保留前 500 個樣本（極其適合用於開發階段的快速驗證）
debug_dataset = Subset(full_dataset, indices=range(500))

# 條件過濾：例如只保留標籤為 0 的樣本
# 注意：這需要我們先遍歷一遍原始資料集的標籤
indices_class_0 = [i for i in range(len(full_dataset)) if full_dataset[i][1] == 0]
class_0_dataset = Subset(full_dataset, indices_class_0)
```

## 拼接資料集：`ConcatDataset`

如果你手頭有多個來源的資料集（例如：分別收集於 2022 年和 2023 年的兩批資料），並希望將它們合併起來一起訓練，`ConcatDataset` 是你的最佳選擇。

```python
from torch.utils.data import ConcatDataset

dataset_2022 = datasets.FakeData(size=5000)
dataset_2023 = datasets.FakeData(size=3000)

# 合併它們 (合併後的資料集總長度為 8000)
merged_dataset = ConcatDataset([dataset_2022, dataset_2023])
```

## 修改 DataLoader 的組裝行為

有時候你的 `Dataset` 完全沒問題，問題出在 `DataLoader` 組裝批次 (batch) 的方式上。

### 注入自訂的 `collate_fn`
預設的 `DataLoader` 假設一個 batch 裡的所有張量形狀一模一樣，然後使用 `torch.stack` 把它們生硬地堆疊起來。如果你的資料集返回的是**變長資料**（例如長度不一的 NLP 句子，或者大小不同的影像），預設的 `DataLoader` 直接就會報錯崩潰。

你必須透過注入自訂的 `collate_fn`（整理函式），在 DataLoader 內部進行動態填充 (Padding)。

```python
from torch.utils.data import DataLoader
from torch.nn.utils.rnn import pad_sequence

def custom_padding_collate(batch):
    # batch 是一個列表，裡面的元素是 Dataset 吐出的元組：[(tensor1, label1), (tensor2, label2), ...]
    sequences = [item[0] for item in batch]
    labels = [item[1] for item in batch]
    
    # 將這個 batch 裡的所有序列，動態填充至當前 batch 中最長序列的長度
    padded_sequences = pad_sequence(sequences, batch_first=True, padding_value=0)
    labels = torch.tensor(labels)
    
    return padded_sequences, labels

# 將自訂邏輯注入 DataLoader
loader = DataLoader(custom_dataset, batch_size=32, collate_fn=custom_padding_collate)
```

### 使用 Samplers 處理類別不平衡
如果你的資料集極度不平衡（例如：90% 是正常樣本，10% 是異常樣本），不要傻傻地去硬碟上複製檔案來擴充資料。你應該修改 `DataLoader` 的採樣策略，將預設的隨機採樣器替換為帶有權重的 `WeightedRandomSampler`。

```python
from torch.utils.data import WeightedRandomSampler

# 1. 根據樣本的類別，為每個樣本計算被抽中的權重
# (假設 0 類是絕大多數，1 類是少數，我們給 1 類賦予高權重)
weights = [0.1 if label == 0 else 0.9 for _, label in custom_dataset]

# 2. 實例化採樣器
sampler = WeightedRandomSampler(weights, num_samples=len(weights), replacement=True)

# 3. 注入 DataLoader 
# (注意：一旦使用了自訂採樣器，DataLoader 的 shuffle 參數必須設定為 False)
balanced_loader = DataLoader(custom_dataset, batch_size=32, sampler=sampler)
```

## 總結

當你有一種衝動想要去從零手寫一個龐大的自訂 `Dataset` 類別時，先問問自己能否用這些「外科手術」技巧來解決問題：
- 使用 **包裝器 (Wrappers)** 攔截並修改資料輸出。
- 使用 **`Subset` / `random_split` / `ConcatDataset`** 切片、過濾或拼接資料。
- 注入 **`collate_fn`** 解決變長資料的打包問題。
- 注入 **`WeightedRandomSampler`** 優雅地應對類別不平衡。
