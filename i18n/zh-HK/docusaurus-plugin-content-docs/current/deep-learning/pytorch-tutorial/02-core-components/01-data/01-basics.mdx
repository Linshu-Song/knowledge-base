# Dataset 與 DataLoader 基礎

高效的數據載入是任何深度學習管道的重要組成部分。PyTorch 提供了兩個核心的數據原語：`torch.utils.data.Dataset` 和 `torch.utils.data.DataLoader`。它們允許您將數據預處理程式碼與模型訓練程式碼解耦，從而提高可讀性和模組化。

## `Dataset`

`Dataset` 儲存樣本及其相應的標籤。要建立自訂資料集，您必須建立一個繼承自 `torch.utils.data.Dataset` 的類別，並實作三個基本方法：

1. `__init__`：初始化包含資料、轉換以及任何其他必要設定的目錄。
2. `__len__`：返回資料集中的樣本總數。
3. `__getitem__`：檢索資料集中給定索引 `idx` 處的樣本。

### 範例：自訂圖像資料集

```python
import os
from PIL import Image
from torch.utils.data import Dataset
from torchvision import transforms

class CustomImageDataset(Dataset):
    def __init__(self, annotations_file, img_dir, transform=None):
        self.img_labels = self._load_annotations(annotations_file)
        self.img_dir = img_dir
        self.transform = transform

    def _load_annotations(self, file_path):
        # 載入標籤的實作
        return [("img1.jpg", 0), ("img2.jpg", 1)]

    def __len__(self):
        return len(self.img_labels)

    def __getitem__(self, idx):
        img_path = os.path.join(self.img_dir, self.img_labels[idx][0])
        image = Image.open(img_path).convert("RGB")
        label = self.img_labels[idx][1]
        
        if self.transform:
            image = self.transform(image)
            
        return image, label
```

## `DataLoader`

`Dataset` 每次檢索我們資料集的特徵和標籤的一個樣本。在模型訓練期間，您通常希望以「小批次」（minibatches）的形式傳遞樣本，在每個輪次（epoch）重新洗牌資料以減少模型過度擬合，並使用 Python 的多處理程序來加速資料檢索。

`DataLoader` 是一個可迭代物件，它抽象了這種複雜性。

```python
from torch.utils.data import DataLoader

# 實例化資料集
transform = transforms.ToTensor()
dataset = CustomImageDataset(
    annotations_file="labels.csv", 
    img_dir="img_dir", 
    transform=transform
)

# 建立 DataLoader
dataloader = DataLoader(
    dataset, 
    batch_size=64, 
    shuffle=True, 
    num_workers=4,
    pin_memory=True
)
```

### 關鍵參數

| 參數 | 目的 | 推薦設定 |
| :--- | :--- | :--- |
| `batch_size` | 每個批次的樣本數 | 取決於 GPU 記憶體（例如 32、64、128） |
| `shuffle` | 隨機化資料順序 | 訓練集設為 `True`，驗證/測試集設為 `False` |
| `num_workers` | 用於資料載入的子處理程序數 | 從 `4` 或 `8` 開始（監控 CPU/GPU 利用率） |
| `pin_memory` | 更快地將資料傳輸到支援 CUDA 的 GPU | 如果使用 GPU 則設為 `True` |
