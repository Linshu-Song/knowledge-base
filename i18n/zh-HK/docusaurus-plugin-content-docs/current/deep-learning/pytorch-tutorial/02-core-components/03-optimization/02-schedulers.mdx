# 學習率排程器

雖然選擇正確的最佳化器很重要，但在訓練期間動態改變學習率（LR）對於達到全域最小值至關重要。`torch.optim.lr_scheduler` 中的排程器旨在根據輪次（epoch）數或一組預先定義的里程碑來調整學習率。

## 排程器如何運作

排程器使用最佳化器物件進行初始化，並隨著時間的推移調整其參數組的 `lr` 屬性。

```python
import torch.optim as optim

optimizer = optim.AdamW(model.parameters(), lr=0.1)
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# 訓練迴圈
for epoch in range(100):
    # 訓練模型...
    train(...)
    # 評估...
    val(...)
    # 根據輪次進度調整學習率
    scheduler.step()
```

:::warning
您應該始終在 `optimizer.step()` *之後* 呼叫 `scheduler.step()`。在此之前呼叫將導致第一個 epoch 使用排程器定義的 *第二個* 學習率，而不是初始學習率。
:::

## 常見排程策略

PyTorch 提供了幾種內建的排程策略。

### `StepLR` 和 `MultiStepLR`

每隔 `step_size` 個輪次（在 `StepLR` 中）或在特定里程碑輪次（在 `MultiStepLR` 中），將學習率衰減一個乘法因子（`gamma`）。

```python
# 每 30 個 epoch 將學習率降低 0.1 倍
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# 在第 30、80 和 120 個 epoch 將學習率降低 0.1 倍
scheduler = optim.lr_scheduler.MultiStepLR(optimizer, milestones=[30, 80, 120], gamma=0.1)
```

### `ReduceLROnPlateau`

此排程器在某個指標停止改善時起作用。例如，當驗證損失停止下降時，該排程器將自動降低學習率，以幫助模型逃離鞍點並收斂。

```python
scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, mode='min', factor=0.1, patience=10)

# 在訓練迴圈中：它需要被監控的指標
for epoch in range(100):
    train(...)
    val_loss = val(...)
    scheduler.step(val_loss) # 將驗證指標傳遞給排程器
```

### `CosineAnnealingLR`

根據餘弦退火（cosine annealing）計畫設定學習率。這種技術很受歡迎，因為它以高學習率開始，迅速下降，然後慢慢穩定在較低的學習率，通常能產生穩健的泛化。

```python
# T_max 是最大迭代次數
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100, eta_min=1e-6)
```

### `OneCycleLR`

單週期策略（One Cycle Policy）。它將學習率從較低的初始值掃描到非常高的峰值（在訓練的第一階段），然後下降到比初始速率低得多的值（在第二階段）。這種方法通常會導致「超收斂（super-convergence）」，從而在防止模型陷入尖銳最小值的同時，極大地加快了訓練速度。

```python
# 需要每個 epoch 的總步數（例如 len(dataloader)）
scheduler = optim.lr_scheduler.OneCycleLR(
    optimizer, 
    max_lr=1e-2, 
    steps_per_epoch=len(train_loader), 
    epochs=100
)

# 關鍵區別：對於 OneCycleLR，步驟在每個批次（BATCH）之後呼叫，而不是每個 epoch。
for epoch in range(100):
    for batch in train_loader:
        train(...)
        scheduler.step()
```

## 排程器比較

| 排程器 | 最佳用例 | 優點/缺點 |
| :--- | :--- | :--- |
| **StepLR** / **MultiStepLR** | 傳統架構（例如 ImageNet 上的 ResNet） | 易於理解 / 硬邊界可能會導致準確率突然下降。 |
| **ReduceLROnPlateau** | 當總輪次（epoch）未知時。 | 反應性，適應當前模型狀態 / 高度依賴於指標雜訊。 |
| **CosineAnnealingLR** | 許多現代網路的標準計畫。 | 平滑衰減 / 需要明確設定 `T_max`。 |
| **OneCycleLR** | 更快的訓練收斂，複雜任務（NLP/Vision）。 | 充當正規化器 / 對 `max_lr` 調整敏感。需要批次級別的更新。 |
