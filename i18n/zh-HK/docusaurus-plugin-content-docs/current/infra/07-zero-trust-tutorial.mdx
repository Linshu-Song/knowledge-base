# Cloudflare Zero Trust 指南

我們利用 **Cloudflare Zero Trust** 確保對內部基礎設施和服務的安全、身份驗證訪問。這種方法用基於身份的安全邊界取代了傳統的 VPN 架構。本指南提供了設備入網的操作步驟。

## Zero Trust 安全模型

訪問基於經過驗證的身份和設備狀況 (Device Posture) 進行控制，而非網絡位置。

- **基於身份的身份驗證**：與您的企業憑據綁定的細粒度訪問控制。
- **細粒度安全策略**：按應用程序或服務定義訪問規則。
- **設備狀況監控**：確保只有安全、經過團隊授權的設備可以連接。
- **優化的性能**：利用全球邊緣網絡實現高速、低延遲路由。

## 桌面基礎設施 (Windows, macOS, Linux)

### 軟件安裝
- **Windows / macOS**：下載 [Cloudflare WARP 客戶端](https://cloudflarewarp.com/)。
- **Linux**：遵循官方 [WARP Linux 倉庫設置](https://developers.cloudflare.com/cloudflare-one/connections/connect-devices/warp/)。

### 企業配置
1. 打開 WARP 客戶端界面。
2. 導航至 **Preferences (首選項) → Account (賬戶)**。
3. 選擇 **Login with Cloudflare Zero Trust (登錄到 Cloudflare Zero Trust)**。
4. 輸入組織團隊名稱：`<YOUR_TEAM_NAME>`（請替換為您的團隊名稱，或如有需要請諮詢您的負責人）。
5. 完成基於瀏覽器的身份驗證工作流。
6. 通過切換到 **Connected (已連接)** 啟用連接。

## 移動基礎設施 (iOS, Android)

### 軟件安裝
- **iOS**：安裝 [Cloudflare One Agent](https://apps.apple.com/us/app/cloudflare-one-agent/id6443476492)。
- **Android**：安裝 [Cloudflare One Agent](https://play.google.com/store/apps/details?id=com.cloudflare.cloudflareoneagent)。

### 連通性配置
1. 啟動應用程序並授予必要權限。
2. 導航至 **Menu (菜單) → Account (賬戶) → Login to Cloudflare Zero Trust**。
3. 輸入團隊名稱：`<YOUR_TEAM_NAME>`。
4. 進行身份驗證並激活連接開關。

## 操作驗證

使用以下指標驗證您的連接狀態：

| 指標 | 驗證方法 | 預期結果 |
| :--- | :--- | :--- |
| **Warp 狀態** | [Cloudflare Trace](https://www.cloudflare.com/cdn-cgi/trace) | `warp=on` 或 `gateway=on` |
| **內部訪問** | 導航至內部 URL | 成功 (例如：`https://admin.internal.site`) |
| **身份驗證** | 查看 WARP 賬戶選項卡 | 使用企業郵箱處於激活狀態 |

---

:::info 支持與訪問控制
身份驗證失敗或“Forbidden”錯誤通常表示您的設備哈希尚未在控制面板中註冊，或者您的賬戶缺少特定的策略權限。請向運維團隊提交訪問配置請求。
:::
