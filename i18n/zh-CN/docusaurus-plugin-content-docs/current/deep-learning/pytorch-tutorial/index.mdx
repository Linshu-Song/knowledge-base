# PyTorch 教程

欢迎来到 PyTorch 教程知识库！

本教程采用模块化的树状结构进行组织，专为可扩展式学习而设计。无论您是在构建第一个神经网络，还是在多个 GPU 上扩展大型语言模型，您都能在这里找到相关的指南。

## 结构概览

1. **基础入门 (`01-fundamentals`)**：PyTorch 的基石，涵盖张量操作和 `autograd` 自动微分引擎。
2. **核心工程组件 (`02-core-components`)**：您将每天使用的工程必备品：`Dataset`、`DataLoader`、`nn.Module`、自定义层和优化策略。
3. **高级进阶与优化 (`03-advanced-optimization`)**：生产规模深度学习的技术，包括分布式数据并行 (DDP)、全切片数据并行 (FSDP) 和混合精度 (AMP)。
4. **高层框架 (`04-frameworks`)**：如 PyTorch Lightning 等自动化了样板工程任务的高级库。
5. **垂直领域实战 (`05-domain-applications`)**：特定任务的垂直领域实现，涵盖从计算机视觉和自然语言处理到时间序列预测的内容。
