# 学习率调度器

虽然选择正确的优化器很重要，但在训练期间动态改变学习率（LR）对于达到全局最小值至关重要。`torch.optim.lr_scheduler` 中的调度器旨在根据轮次（epoch）数或一组预定义的里程碑来调整学习率。

## 调度器如何工作

调度器使用优化器对象进行初始化，并随着时间的推移调整其参数组的 `lr` 属性。

```python
import torch.optim as optim

optimizer = optim.AdamW(model.parameters(), lr=0.1)
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# 训练循环
for epoch in range(100):
    # 训练模型...
    train(...)
    # 评估...
    val(...)
    # 根据轮次进度调整学习率
    scheduler.step()
```

:::warning
您应该始终在 `optimizer.step()` *之后* 调用 `scheduler.step()`。在此之前调用将导致第一个 epoch 使用调度器定义的 *第二个* 学习率，而不是初始学习率。
:::

## 常见调度策略

PyTorch 提供了几种内置的调度策略。

### `StepLR` 和 `MultiStepLR`

每隔 `step_size` 个轮次（在 `StepLR` 中）或在特定里程碑轮次（在 `MultiStepLR` 中），将学习率衰减一个乘法因子（`gamma`）。

```python
# 每 30 个 epoch 将学习率降低 0.1 倍
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# 在第 30、80 和 120 个 epoch 将学习率降低 0.1 倍
scheduler = optim.lr_scheduler.MultiStepLR(optimizer, milestones=[30, 80, 120], gamma=0.1)
```

### `ReduceLROnPlateau`

此调度器在某个指标停止改善时起作用。例如，当验证损失停止下降时，该调度器将自动降低学习率，以帮助模型逃离鞍点并收敛。

```python
scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, mode='min', factor=0.1, patience=10)

# 在训练循环中：它需要被监控的指标
for epoch in range(100):
    train(...)
    val_loss = val(...)
    scheduler.step(val_loss) # 将验证指标传递给调度器
```

### `CosineAnnealingLR`

根据余弦退火（cosine annealing）计划设置学习率。这种技术很受欢迎，因为它以高学习率开始，迅速下降，然后慢慢稳定在较低的学习率，通常能产生稳健的泛化。

```python
# T_max 是最大迭代次数
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100, eta_min=1e-6)
```

### `OneCycleLR`

单周期策略（One Cycle Policy）。它将学习率从较低的初始值扫描到非常高的峰值（在训练的第一阶段），然后下降到比初始速率低得多的值（在第二阶段）。这种方法通常会导致“超收敛（super-convergence）”，从而在防止模型陷入尖锐最小值的同时，极大地加快了训练速度。

```python
# 需要每个 epoch 的总步数（例如 len(dataloader)）
scheduler = optim.lr_scheduler.OneCycleLR(
    optimizer, 
    max_lr=1e-2, 
    steps_per_epoch=len(train_loader), 
    epochs=100
)

# 关键区别：对于 OneCycleLR，步骤在每个批次（BATCH）之后调用，而不是每个 epoch。
for epoch in range(100):
    for batch in train_loader:
        train(...)
        scheduler.step()
```

## 调度器比较

| 调度器 | 最佳用例 | 优点/缺点 |
| :--- | :--- | :--- |
| **StepLR** / **MultiStepLR** | 传统架构（例如 ImageNet 上的 ResNet） | 易于理解 / 硬边界可能会导致准确率突然下降。 |
| **ReduceLROnPlateau** | 当总轮次（epoch）未知时。 | 反应性，适应当前模型状态 / 高度依赖于指标噪声。 |
| **CosineAnnealingLR** | 许多现代网络的标准计划。 | 平滑衰减 / 需要明确设置 `T_max`。 |
| **OneCycleLR** | 更快的训练收敛，复杂任务（NLP/Vision）。 | 充当正则化器 / 对 `max_lr` 调整敏感。需要批次级别的更新。 |
