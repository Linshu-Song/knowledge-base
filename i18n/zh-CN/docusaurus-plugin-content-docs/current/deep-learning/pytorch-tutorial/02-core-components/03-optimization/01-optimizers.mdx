# 优化器

优化器是深度学习中的核心组件，用于更新神经网络的状态（如权重和偏置）以最小化损失函数。

从数学上讲，函数的梯度指向的是其数值增长最快的方向。而在深度学习中，我们的目标是寻找损失函数的最小值（即寻找“谷底”），因此优化算法会沿着 **梯度的负方向** 更新参数，从而实现损失的持续下降。

在 PyTorch 中，所有的优化算法都封装在 `torch.optim` 模块下。

## 基本用法

使用优化器通常需要两个步骤：首先传入模型参数进行实例化，然后在训练循环中调用更新方法。

```python
import torch.optim as optim

# 1. 实例化优化器：传入参数列表（model.parameters()）并设置学习率
optimizer = optim.Adam(model.parameters(), lr=1e-3)

# 2. 训练循环内部的标准步骤
optimizer.zero_grad()  # 清除上一步留下的旧梯度
loss.backward()        # 计算当前步的梯度（反向传播）
optimizer.step()       # 根据梯度更新模型参数
```

:::danger[关键步骤]
**务必在 `loss.backward()` 之前调用 `optimizer.zero_grad()`**。PyTorch 默认会累加梯度（这种设计是为了支持多步更新或大 Batch 模拟），如果不手动清零，会导致梯度计算错误，模型将无法收敛。
:::

## 常见优化器解析

选择合适的优化器对模型的收敛速度和最终性能至关重要。

### 随机梯度下降 (SGD)

最经典的优化算法。它沿着梯度的负方向更新参数。在实际应用中，通常会结合 **动量 (Momentum)** 机制，利用惯性加速在正确方向上的搜索并抑制震荡。

“随机”一词的含义：实践中，SGD 通常不会在每次更新时对整个训练集计算精确梯度，而是使用随机抽样得到的一个子集（即 mini-batch）或甚至单个样本来估计梯度。这样做使单次更新的计算成本大幅降低、更新更频繁，并且由噪声引入的随机性有时能帮助优化器跳出浅层局部最小值。其权衡是梯度估计的方差增加，因此需要通过调整批量大小（batch size）和学习率来取得稳健训练。

```python
# 带 Nesterov 动量的 SGD（通常比普通动量收敛更稳健）
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9, nesterov=True)
```

### Adam

Adam (Adaptive Moment Estimation) 结合了动量和自适应学习率的思想。它会根据梯度的一阶矩（均值）和二阶矩（方差）为每个参数动态调整学习率。由于其“开箱即用”的特性和极快的初始收敛速度，Adam 是目前大多数任务的首选。

```python
# 标准 Adam 优化器
optimizer = optim.Adam(model.parameters(), lr=0.001, betas=(0.9, 0.999), eps=1e-08)
```

### AdamW

Adam 的改良版。它将 **权重衰减 (Weight Decay)** 从梯度更新中解耦出来。实验证明，AdamW 在 Transformer、大型视觉模型等现代架构上的泛化性能优于传统 Adam。

```python
# 现代深度学习架构（如 Transformer）的首选
optimizer = optim.AdamW(model.parameters(), lr=1e-4, weight_decay=1e-2)
```

## 核心选型对比

| 优化器 | 优势 | 劣势 | 推荐场景 |
| :--- | :--- | :--- | :--- |
| **SGD (+Momentum)** | 通常能找到更平坦、泛化性更好的解。 | 学习率和动量极其敏感，初始收敛慢。 | 图像分类 (ResNet 系列)、科研调优。 |
| **Adam** | 收敛极快，对超参数初值不敏感。 | 后期可能出现不收敛或泛化不如 SGD。 | GAN、常规 MLP、快速原型开发。 |
| **AdamW** | 解决了 Adam 的权重衰减失效问题，泛化性极佳。 | 同样需要精细调整 `weight_decay`。 | **Transformer (NLP/CV)**、SOTA 模型训练。 |

## 进阶：分层学习率 (Parameter Groups)

你可以通过向优化器传递字典列表，为模型不同层设置差异化的超参数。这在 **迁移学习 (Transfer Learning)** 和 **微调 (Fine-tuning)** 中非常有用。

```python
# 案例：以较小步长微调特征提取层，以较大步长训练分类层
optimizer = optim.SGD([
    {'params': model.backbone.parameters(), 'lr': 1e-4},
    {'params': model.classifier.parameters(), 'lr': 1e-2}
], momentum=0.9)
```
