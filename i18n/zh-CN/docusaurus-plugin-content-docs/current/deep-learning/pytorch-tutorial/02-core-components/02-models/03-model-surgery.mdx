# 模型修改

对于深度学习工程师而言，最日常的工作往往不是从零开始从头训练一个模型，而是将现有的、在海量数据上预训练好的模型迁移到全新的任务中。这个对模型进行探查、修改、截取的过程，在业界常被称为**模型手术 (Model Surgery)**。

面对像 ResNet 或是 Vision Transformer (ViT) 这样庞大且深层的网络，初级开发者可能会感到无从下手。本指南将提供一套标准的操作流程，让你能够自信地对任何 PyTorch 模型进行“开刀”。

## 第一步：探查模型架构

在进行任何修改之前，你必须先彻底了解模型的精确层级结构。PyTorch 的模块是一棵深度嵌套的树。

### 最直接的方法：`print(model)`
直接打印模型会输出其完整的嵌套结构。虽然输出可能非常冗长，但它精确地显示了每个子模块的内部变量名——这正是你在代码中访问它们所需的名称。

```python
import torchvision.models as models

model = models.resnet18()
print(model)
# 输出节选：
# ResNet(
#   (conv1): Conv2d(3, 64, kernel_size=(7, 7), stride=(2, 2), padding=(3, 3), bias=False)
#   (bn1): BatchNorm2d(64, eps=1e-05, momentum=0.1, affine=True, track_running_stats=True)
#   (relu): ReLU(inplace=True)
#   ...
#   (fc): Linear(in_features=512, out_features=1000, bias=True)
# )
```

从上面的输出中我们可以清晰地看到，第一层卷积被存放在 `model.conv1`，而最后的分类头则被存放在 `model.fc`。

:::tip[使用 `torchinfo` 库]
如果你需要更专业、更易读的汇总信息（包括每一层的输出张量形状以及参数量），强烈建议使用第三方库 `torchinfo`。
```python
from torchinfo import summary
summary(model, input_size=(1, 3, 224, 224))
```
:::

## 第二步：替换子模块

迁移学习中最经典的场景，是将一个在 ImageNet（包含 1000 个类别）上训练好的模型，适配到一个自定义数据集（例如猫狗分类，只有 2 个类别）。

要实现这一点，我们只需要用一个全新的层覆盖掉模型原有的最后一层即可。

```python
import torch.nn as nn

# 1. 找到最后一层分类器的输入维度 (例如 ResNet 的叫 'fc'，MobileNet 的叫 'classifier')
in_features = model.fc.in_features

# 2. 用一个全新的、未训练的层替换它
model.fc = nn.Linear(in_features, out_features=2)
```

通过直接将新的 `nn.Linear` 赋值给 `model.fc`，PyTorch 会自动注销掉旧层的参数，并注册新层的参数。新层在创建时默认会进行随机初始化。

:::warning[命名习惯的差异]
不同经典架构对最后一层的命名各不相同。ResNet 习惯叫 `.fc`，VGG 和 DenseNet 习惯叫 `.classifier`，而 Vision Transformers (ViT) 则叫 `.heads`。**动手前请务必先 print() 打印模型！**
:::

## 第三步：冻结参数 (Freezing)

如果你只想训练刚刚新加的那一层（这种技术被称为线性探测 Linear Probing），你必须“冻结”模型其余部分。所谓“冻结”，就是告诉 PyTorch 的 Autograd 自动求导引擎，不要去计算这些参数的梯度。这能节省极其可观的显存和计算时间。

```python
# 1. 冻结整个模型的所有参数
for param in model.parameters():
    param.requires_grad = False

# 2. 仅仅解冻刚刚新加的那一层的参数
# (注意：新建层默认是 requires_grad=True 的，但如果你是在替换层之后才执行了全局冻结，就必须手动解冻它)
for param in model.fc.parameters():
    param.requires_grad = True
```

在将参数传递给优化器时，最佳实践是**只传入那些未被冻结的参数**：
```python
optimizer = torch.optim.Adam(
    filter(lambda p: p.requires_grad, model.parameters()), 
    lr=1e-3
)
```

## 第四步：提取中间层特征

有时候你根本不关心模型的最终输出，而是需要提取模型中间某些层生成的特征图（这在目标检测、语义分割或神经风格迁移中非常常见）。

### “暴力重写”法（极不推荐）
新手最容易犯的错误，就是去框架源码里把整个 `forward` 函数复制粘贴出来，然后修改其中的代码让它返回多个张量。**请绝对不要这么做。** 一旦官方修复了底层实现或是版本更新，你的代码立刻就会崩溃，维护成本极高。

### 钩子函数法 Hook（专业做法）
PyTorch 提供了 `register_forward_hook`，允许你在任何模块上挂载一个“监听器”。每次该模块完成前向传播时，钩子函数都会被触发，让你能够直接拿到它的输入和输出。

```python
intermediate_features = {}

def get_features(name):
    # 这个 hook 会在模型前向传播时被自动调用
    def hook(module, input, output):
        intermediate_features[name] = output.detach()
    return hook

# 将钩子挂载到我们关心的特征层上
model.layer1.register_forward_hook(get_features('feat1'))
model.layer3.register_forward_hook(get_features('feat3'))

# 正常执行前向计算
x = torch.randn(1, 3, 224, 224)
_ = model(x)

# 字典中现在已经悄悄存好了我们需要的中间张量！
print(intermediate_features['feat1'].shape)
```

### 现代图追踪法：Feature Extractor
从 PyTorch 1.11 开始，官方提供了一个极其优雅的工具 `torchvision.models.feature_extraction`。它利用底层计算图追踪 (`torch.fx`)，自动在后台帮你把模型“重写”了一遍。

```python
from torchvision.models.feature_extraction import create_feature_extractor

# 定义一个字典，将内部节点的路径映射为你想要的自定义键名
return_nodes = {
    'layer1.2.relu': 'feat1',
    'layer3.5.relu': 'feat3'
}

# 创建一个专门用于输出你所指定特征的全新模型
feature_extractor = create_feature_extractor(model, return_nodes=return_nodes)

# 它的输出直接就是一个字典！
out = feature_extractor(x)
print(out['feat1'].shape)
```

## 总结

对现成的预训练模型进行修改，是一项必备的工程基本功。请牢记这个标准工作流：
1. **探查**：通过 `print` 或 `torchinfo` 确认具体的层名和架构。
2. **替换**：使用标准的 Python 赋值 (`model.layer_name = new_layer`) 覆盖子模块。
3. **冻结**：通过设置 `requires_grad = False` 锁定底层特征，防止灾难性遗忘并加速训练。
4. **提取**：优雅地使用 Hook 或 `create_feature_extractor` 获取中间特征，坚决避免去复制和重写臃肿的 `forward` 函数。
