PyTorch 教程

PyTorch 是一个用于 Python 的开源机器学习框架，被广泛用于研究与生产环境。它的两个核心特性是：

  • 高效的张量库并对 GPU 有良好支持。
  • 支持动态图的自动微分引擎（Autograd）。

本教程侧重于实用工程模式：如何使用张量与设备、使用 torch.nn.Module 构建模型、准备高性能数据管道以及应用现代训练技巧来进行实验与部署。

如果你是初学者，建议从基础篇（Fundamentals）开始学习张量和自动微分；如果你要维护或上线模型，核心组件（Core Components）部分覆盖了日常工程模式。
