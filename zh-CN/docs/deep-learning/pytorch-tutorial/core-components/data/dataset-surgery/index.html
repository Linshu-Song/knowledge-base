数据集修改

在实际工程中，你极少需要从零开始手写一个完整的 PyTorch Dataset。通常情况下，我们会从 torchvision 或 Hugging Face 下载标准数据集，这些数据“差不多”符合我们的需求，但总需要一些客制化的微调。

与其复制底层源码并重写整个数据集类，最佳实践是修改、包装（Wrap）或组合现有的数据集。本指南将展示如何进行优雅的“数据集手术”。

包装器模式 (Wrapper Pattern)：修改输出格式​

假设你正在使用 torchvision.datasets.CIFAR10，它默认返回的元组是 (image, label)。但如果你在做对比学习，或者需要追踪样本，想要它返回 (image, label, image_index) 怎么办？

不要去重写 CIFAR10 的类，你可以创建一个包装器数据集 (Wrapper Dataset)。它将原始数据集作为属性接收，并在 __getitem__ 阶段拦截并修改输出。

import torch
from torch.utils.data import Dataset
from torchvision import datasets, transforms

class IndexWrapperDataset(Dataset):
    """包装现有数据集，使其在返回数据的同时附加样本的索引 (index)。"""
    
    def __init__(self, original_dataset):
        self.original_dataset = original_dataset
        
    def __len__(self):
        # 将长度查询委托给原始数据集
        return len(self.original_dataset)
        
    def __getitem__(self, index):
        # 1. 获取原始数据
        data, label = self.original_dataset[index]
        
        # 2. 修改它，或者追加自定义的信息
        return data, label, index

# 使用方法
base_dataset = datasets.CIFAR10(root='./data', train=True, download=True, transform=transforms.ToTensor())
custom_dataset = IndexWrapperDataset(base_dataset)

img, label, idx = custom_dataset[0]
print(f"成功加载索引为 {idx} 的图片，标签为 {label}")
覆盖数据增强 (Transforms)

你同样可以使用这种包装器模式，在运行时动态修改、或向那些本身不支持复杂 Transform 流水线的数据集追加自定义的数据增强逻辑。

切片与过滤：Subset 与 Splits​

我们经常需要从庞大的数据集中抽取出极小的一部分用于快速 Debug 跑通代码，或者将一个完整的数据集切分为训练集和验证集。

random_split (训练/验证集划分)​

如果官方数据集没有预先切分验证集，PyTorch 提供了 torch.utils.data.random_split 来帮你一键完成。

from torch.utils.data import random_split

# 假设原始数据集有 10,000 张图像
full_dataset = datasets.FakeData(size=10000, image_size=(3, 224, 224), num_classes=10)

# 定义划分长度 (长度总和必须等于总样本数)
train_size = int(0.8 * len(full_dataset))
val_size = len(full_dataset) - train_size

# 随机切分 (返回两个 Subset 对象)
train_dataset, val_dataset = random_split(full_dataset, [train_size, val_size])
Transform 的数据泄露问题

新手在使用 random_split 时最容易犯的错误，是在切分之前就给 full_dataset 挂载了带有随机性的训练增强（例如 RandomCrop 随机裁剪）。这会导致你的验证集也被加上了随机数据增强！

解决方案：结合第 1 节介绍的“包装器模式”，分别对切分出来的 train_dataset 和 val_dataset 包装不同的 Transform 逻辑。

Subset (条件过滤)​

如果你想根据某些特定条件手动筛选数据（例如，只保留特定类别的样本），请使用 Subset。

from torch.utils.data import Subset

# 过滤：仅保留前 500 个样本（极其适合用于开发阶段的快速验证）
debug_dataset = Subset(full_dataset, indices=range(500))

# 条件过滤：例如只保留标签为 0 的样本
# 注意：这需要我们先遍历一遍原始数据集的标签
indices_class_0 = [i for i in range(len(full_dataset)) if full_dataset[i][1] == 0]
class_0_dataset = Subset(full_dataset, indices_class_0)

拼接数据集：ConcatDataset​

如果你手头有多个来源的数据集（例如：分别收集于 2022 年和 2023 年的两批数据），并希望将它们合并起来一起训练，ConcatDataset 是你的最佳选择。

from torch.utils.data import ConcatDataset

dataset_2022 = datasets.FakeData(size=5000)
dataset_2023 = datasets.FakeData(size=3000)

# 合并它们 (合并后的数据集总长度为 8000)
merged_dataset = ConcatDataset([dataset_2022, dataset_2023])

修改 DataLoader 的组装行为​

有时候你的 Dataset 完全没问题，问题出在 DataLoader 组装批次 (batch) 的方式上。

注入自定义的 collate_fn​

默认的 DataLoader 假设一个 batch 里的所有张量形状一模一样，然后使用 torch.stack 把它们生硬地堆叠起来。如果你的数据集返回的是变长数据（例如长度不一的 NLP 句子，或者大小不同的图像），默认的 DataLoader 直接就会报错崩溃。

你必须通过注入自定义的 collate_fn（整理函数），在 DataLoader 内部进行动态填充 (Padding)。

from torch.utils.data import DataLoader
from torch.nn.utils.rnn import pad_sequence

def custom_padding_collate(batch):
    # batch 是一个列表，里面的元素是 Dataset 吐出的元组：[(tensor1, label1), (tensor2, label2), ...]
    sequences = [item[0] for item in batch]
    labels = [item[1] for item in batch]
    
    # 将这个 batch 里的所有序列，动态填充至当前 batch 中最长序列的长度
    padded_sequences = pad_sequence(sequences, batch_first=True, padding_value=0)
    labels = torch.tensor(labels)
    
    return padded_sequences, labels

# 将自定义逻辑注入 DataLoader
loader = DataLoader(custom_dataset, batch_size=32, collate_fn=custom_padding_collate)

使用 Samplers 处理类别不平衡​

如果你的数据集极度不平衡（例如：90% 是正常样本，10% 是异常样本），不要傻傻地去硬盘上复制文件来扩充数据。你应该修改 DataLoader 的采样策略，将默认的随机采样器替换为带有权重的 WeightedRandomSampler。

from torch.utils.data import WeightedRandomSampler

# 1. 根据样本的类别，为每个样本计算被抽中的权重
# (假设 0 类是绝大多数，1 类是少数，我们给 1 类赋予高权重)
weights = [0.1 if label == 0 else 0.9 for _, label in custom_dataset]

# 2. 实例化采样器
sampler = WeightedRandomSampler(weights, num_samples=len(weights), replacement=True)

# 3. 注入 DataLoader 
# (注意：一旦使用了自定义采样器，DataLoader 的 shuffle 参数必须设置为 False)
balanced_loader = DataLoader(custom_dataset, batch_size=32, sampler=sampler)

总结​

当你有一种冲动想要去从零手写一个庞大的自定义 Dataset 类时，先问问自己能否用这些“外科手术”技巧来解决问题：

  • 使用 包装器 (Wrappers) 拦截并修改数据输出。
  • 使用 Subset / random_split / ConcatDataset 切片、过滤或拼接数据。
  • 注入 collate_fn 解决变长数据的打包问题。
  • 注入 WeightedRandomSampler 优雅地应对类别不平衡。
