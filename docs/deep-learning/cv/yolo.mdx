# YOLO

**You Only Look Once** — Real-time object detection architecture.

YOLO is a family of single-stage object detection models that process images in a single forward pass, making them extremely fast compared to two-stage detectors.

## Evolution

| Version | Year | Key Innovation |
|---------|------|----------------|
| YOLOv1 | 2016 | First single-stage detector |
| YOLOv2 | 2017 | Batch normalization, anchor boxes |
| YOLOv3 | 2018 | Feature pyramid networks |
| YOLOv4 | 2020 | CSPDarknet, mosaic augmentation |
| YOLOv5 | 2020 | PyTorch implementation |
| YOLOv6 | 2022 | Industrial-focused optimizations |
| YOLOv7 | 2022 | E-ELAN architecture |
| YOLOv8 | 2023 | Unified framework |
| YOLOv9 | 2024 | Programmable Gradient Information |
