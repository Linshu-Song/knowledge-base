Optimizers

Optimizers are core components in deep learning used to update a neural network's state (such as weights and biases) to minimize a loss function.

Mathematically, the gradient of a function points in the direction of the steepest ascent. Since our goal in deep learning is to find the minimum of the loss function (the "valley"), optimization algorithms move parameters in the negative gradient direction to achieve this.

In PyTorch, all optimization algorithms are encapsulated in the torch.optim package.

Basic Usage​

To use an optimizer, you must instantiate it by passing an iterable containing the parameters (tensors that should be optimized) and optionally setting optimizer-specific options like the learning rate (lr).

import torch.optim as optim

# Instantiate the optimizer
optimizer = optim.Adam(model.parameters(), lr=1e-3)

# Inside the training loop
optimizer.zero_grad()  # 1. Clear old gradients
loss.backward()        # 2. Compute new gradients (backpropagation)
optimizer.step()       # 3. Update parameters
Critical Step

Always call optimizer.zero_grad() before computing the loss gradients (via loss.backward()). By default, gradients are accumulated in PyTorch. Failing to clear them will lead to incorrect updates.

Common Optimizers​

The choice of optimizer significantly impacts the model's convergence speed and final accuracy.

Stochastic Gradient Descent (SGD)​

The classic algorithm. It updates parameters in the negative gradient direction. It often benefits from Momentum, which helps accelerate gradients in the right direction, dampening oscillations.

Note on "stochastic": in practice, SGD does not usually compute the exact gradient over the entire training dataset at every update. Instead, it computes a (noisy) gradient estimate using a randomly sampled subset of examples (a "mini-batch") or even a single example. This randomness makes updates much cheaper and more frequent, can speed up training, and—because of the noise—sometimes helps the optimizer escape shallow local minima. The trade-off is increased gradient variance, so batch size and learning rate must be tuned.

# SGD with Nesterov momentum
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9, nesterov=True)

Adam​

Adam (Adaptive Moment Estimation) computes individual adaptive learning rates for different parameters from estimates of first and second moments of the gradients. It's often the default choice for many deep learning tasks due to its rapid initial convergence.

# Standard Adam optimizer
optimizer = optim.Adam(model.parameters(), lr=0.001, betas=(0.9, 0.999), eps=1e-08)

AdamW​

A variant of Adam that decouples weight decay from the gradient update. It has been empirically shown to yield better generalization performance than Adam, especially in Transformer models and large vision models.

# AdamW is heavily preferred over Adam for modern architectures
optimizer = optim.AdamW(model.parameters(), lr=1e-4, weight_decay=1e-2)

Parameter Groups​

You can define different learning rates or hyperparameters for different parts of the network by passing an iterable of dictionaries to the optimizer.

# Finetuning example: 
# Train the classifier with a larger learning rate, freeze or train base model slowly
optim.SGD([
    {'params': model.base.parameters(), 'lr': 1e-4},
    {'params': model.classifier.parameters(), 'lr': 1e-2}
], momentum=0.9)
