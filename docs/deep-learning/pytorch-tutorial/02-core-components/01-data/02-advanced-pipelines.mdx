# Advanced Data Pipelines

For massive datasets or streaming scenarios where the data is either generated on the fly or streamed from a remote source, the standard Map-style `Dataset` becomes inefficient or impossible to use. PyTorch provides an advanced primitive called `IterableDataset` and a specialized library called `TorchData`.

:::note
This page is currently under development. The topics below will be expanded in future updates.
:::

## `IterableDataset` and `IterDataPipe`

While a regular `Dataset` relies on indices (`__getitem__`), an `IterableDataset` implements the `__iter__` protocol, producing data points sequentially. 

`IterDataPipe` is a newer paradigm introduced in TorchData that chains operations (e.g., parsing, decoding, batching) directly on iterable data streams.

```python
from torch.utils.data import IterableDataset

class StreamingDataset(IterableDataset):
    def __init__(self, data_stream):
        self.data_stream = data_stream

    def __iter__(self):
        for data in self.data_stream:
            yield self.process(data)
```
