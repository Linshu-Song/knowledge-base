# PyTorch Tutorial

PyTorch is an open-source machine learning library for Python, widely used for research and production. It provides two main features that make it particularly powerful:

- A flexible tensor library with strong GPU acceleration.
- An automatic differentiation engine (Autograd) that supports dynamic computation graphs.

This tutorial focuses on practical engineering patterns: how to work with tensors and devices, build models with torch.nn.Module, prepare efficient data pipelines, and apply modern training techniques for research and production.

If you are new, start with the Fundamentals section to learn tensors and autograd. If you are maintaining or shipping models, the Core Components section covers the engineering patterns you will use daily.
