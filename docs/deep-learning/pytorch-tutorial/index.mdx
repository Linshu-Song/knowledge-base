# PyTorch Tutorial

Welcome to the PyTorch Tutorial knowledge base! 

This tutorial is organized in a modular tree structure designed for scalable learning. Whether you are building your first neural network or scaling a massive language model across multiple GPUs, you can find the relevant guides here.

## Structure Overview

1. **Fundamentals (`01-fundamentals`)**: The bedrock of PyTorch, covering tensor operations and the `autograd` engine.
2. **Core Components (`02-core-components`)**: The engineering staples you'll use daily: `Dataset`, `DataLoader`, `nn.Module`, custom layers, and optimization strategies.
3. **Advanced & Optimization (`03-advanced-optimization`)**: Techniques for production-scale deep learning, including Distributed Data Parallel (DDP), Fully Sharded Data Parallel (FSDP), and mixed precision (AMP).
4. **Frameworks (`04-frameworks`)**: High-level libraries like PyTorch Lightning that automate boilerplate engineering tasks.
5. **Domain Applications (`05-domain-applications`)**: Vertical, task-specific implementations ranging from Computer Vision and Natural Language Processing to Time Series forecasting.
